
# John Beverly | Engineering Portfolio

**Robotics • Automation • Engineering • Innovation**

A personal portfolio showcasing my technical projects, engineering experience, and involvement in robotics, automation, and applied research.

As an Electromechanical Engineering Technology student at St. Clair College, my interests span industrial automation, robotics, product development, and emerging technologies. Through hands-on engineering projects and collaborative initiatives, I aim to bridge the gap between innovative concepts and practical solutions.

## About the Portfolio

This website serves as a central platform to document my technical experience, highlight projects, and share my ongoing development as an engineering technologist.

The portfolio features:

- **Engineering Projects:** Selected work involving robotics, automation, prototyping, and product development.
- **Technical Skills:** Experience with industrial robotics, PLC programming, CAD, electrical systems, and fabrication technologies.
- **Leadership & Innovation:** Contributions to student organizations, engineering initiatives, and interdisciplinary projects.
- **Professional Experience:** An overview of my academic background, accomplishments, and technical interests.

## Design Philosophy

The visual identity draws inspiration from engineering blueprints and technical drafting, combining a muted navy colour palette, subtle grid patterns, and minimalist interface elements.

The design prioritizes:

- Clear and intuitive navigation
- Responsive layouts across devices
- Accessibility and readability
- Lightweight performance
- Flexibility for future development

## Local Development

To run the website locally, clone the repository:

```bash
git clone https://github.com/Bluest-Lotus/My_Portfolio.git
```

Navigate to the project directory and open `index.html` in a web browser.

No additional dependencies or installation steps are required.
